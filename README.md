# Mohit Sharma — Portfolio

Next.js 16 · Tailwind 4 · Three.js · Lenis

```
npm install
npm run dev     # http://localhost:3000
```

- **All content** (bio, experience, projects, skills, education, contact): `src/lib/profile.ts`
- Résumé PDF: `public/Mohit_Sharma_Resume.pdf` · Photo: `public/profile.jpg`
- 3D hero shapes: `src/components/three/shapes.ts`
- Contact form: `src/app/api/contact/route.ts` (set `RESEND_API_KEY` to receive emails)

Hidden extras: `Ctrl+K` command palette, `` Ctrl+` `` terminal (try `whoami`, `sudo hire mohit`).

## Deploy (Vercel)
Push to GitHub → vercel.com → Add New → Project → import → add `NEXT_PUBLIC_SITE_URL` → Deploy.
